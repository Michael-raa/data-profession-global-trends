# 🌍 Data Science Profession: Global Demographics & Trends

## 📌 Project Overview
An interactive dashboard tracking 5 years of global Kaggle Data Science Survey data (2017–2021). This project maps the demographic and professional landscape of the global data industry.

## 🛠️ Tools & Technologies
* **Power BI:** Data visualization, interactive filtering, and dynamic dashboard design.
* **Data Analytics:** Time-series analysis and demographic profiling.

## 📊 Key Business Insights
* **Demographic Shifts:** Visualized global respondent trends, tracking shifts in age distribution and top residing countries (e.g., India, USA).
* **Professional Profiling:** Ranked the most common industry roles (Data Scientist, Data Analyst, Software Engineer) to identify primary career pathways.
* **Education Breakdown:** Analyzed the correlation between formal education levels (Bachelor's, Master's, Doctoral) and industry participation.
